# Read the same workshop through five phases

Use the built-in Wu Xing preset to consider how connected material contributes to a workshop. These phase assignments are a personal reading of these examples, not a universal classification of research, drawing or review.

## Try it

1. Center this note, choose **Facets** in **Views and lenses**, then choose **Wu Xing**.
2. Find one workshop note in each phase. Wood starts at the top; Fire, Earth, Metal and Water follow clockwise.
3. Compare the phase names with their relative labels. This focus is Wood, so Fire is **What I generate** and Earth is **What I regulate**.
4. Center **Keep a lesson from the workshop** (the Workshop review note), which is Metal. Its ordinary Next/Previous connection keeps the materials note reachable. Earth now reads **What generates me**; this note, still Wood, reads **What I regulate**.
5. Return here through the existing connection or navigation history. The original phase assignments are unchanged.

| Connected example | Saved `status` | Why this example uses it |
| --- | --- | --- |
| Research question | 🟢 Wood | Opens a direction to explore |
| A visual note | 🔴 Fire | Makes an idea expressive and visible |
| Workshop materials | 🟤 Earth | Brings resources together into something usable |
| Workshop review | 🟡 Metal | Distills a lesson and a useful boundary |
| A note with sections | 🔵 Water | Keeps context available for reflection |

Inspect **status** in Properties to see the stored value. The focus and the research question share Wood. The materials note stays Earth when the focus changes from Wood to Metal; only its relative role changes.

## Keep three meanings separate

Your saved phase is a choice about a note. The relative label is a model-derived reading between two phases. A note connector comes from an actual recorded relationship. Generating and regulating cycle guides connect regions as explanations; they do not assert that a particular note caused or controls another.

Other linked help pages have no phase and appear in **Unassigned**. Missing metadata does not assign Wood automatically. Two different recognized phases would appear in **Conflicting**; check the property rather than treating either phase as authoritative.

## Make it yours

Duplicate Wu Xing if a different property name or set of aliases fits your notes. Its default is the Markdown property `status`, with the five emojis above; English phase IDs are aliases. Give notes phases intentionally, connect relevant material normally, then use the changing relative labels as prompts for reflection. Assigning a phase does not create relationships.
