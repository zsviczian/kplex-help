# Start with a useful page, then connect it

Capture a workshop plan without rebuilding the same headings each time. This vault includes two plain Markdown templates in its Templates folder; they need no Templater commands.

![[Screenshot - Creation type tabs.png]]

*Desktop: the supplied Workshop plan template is selected. This is the dialog before saving; creating it adds a real note and the reviewed connection.*

## Try it

1. Center [[Example - Workshop plan]] and drag from its Child gate into empty space.
2. Enter a name such as **My next workshop**, choose **Return** under Action, and select the **Markdown** tab.
3. Choose **Template - Workshop plan** in Template and create the note. Read it to see the prompts already in place and the reviewed relationship added to it.
4. Open the dialog again: the type tab is remembered. Choose the Reading note template for a different kind of page, or **No K-Plex template** to use normal creation automation.

The Markdown template folder is configured to Templates in this supplied vault. In your own vault, select a folder with the settings folder suggester. Excalidraw uses its separate template source.

These are real creation steps: they add a note and the relationship you review. Cancel the dialog if you only want to inspect the controls. Use the normal unlink/delete actions to remove practice material afterward.
