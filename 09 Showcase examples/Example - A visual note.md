# Recognize an idea by its picture

Spot an idea before reading its title. This note uses a local Compass image as a thumbnail, so it has a recognizable visual cue in the canvas.

![[Assets/Screenshot - A note with a thumbnail.png]]

*A local Compass thumbnail appears beside the example's label. Local images do not need remote-image permission.*

## Try it

1. Center [[05 Personalize and workspace/Images in nodes|Images in nodes]].
2. Look for this example beneath it: the Compass appears before its title.
3. Open this note's Properties and inspect **thumbnail**. It points to a local SVG already included in the vault.

In your own note, use `thumbnail` for a small image beside the label or `node-image` for an image in place of the label. These default field names can be changed in Settings. A local image needs no remote-image permission.
