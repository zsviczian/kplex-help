# Choose a useful learning route

Understand an idea, try a small action, then apply it to something useful. This example turns existing note types into a route through the help.

## Try it

1. Center this note and choose **Facets → Learning route**.
2. Read the vertical sequence: **Understand**, **Try**, **Apply**.
3. Inspect **Note type** on a connected note. `Concept` leads to Understand, `Guide` to Try, and the existing `Use case` value to Apply.

The two concept notes explain the map, two guides offer small actions, and two use cases put the skills to work. The focus sits beside the sequence. Wider category areas leave room for cards beside one another.

## Make it yours

Use the note-type value you already maintain in your vault. The labels describe how a reader can use a note; they do not require changing the stored values to match. This preset is distinct from Compass's **Group nodes by note type**: Facets puts types into categories you define.
