K-Plex is not simply a renamed ExcaliBrain. It is a new plugin with its own ID, interface and indexing system, designed so **Excalidraw and Dataview are not required**.

For migration, K-Plex can import compatible ExcaliBrain ontology plus graph/node/link styling. The import boundary is intentionally limited: navigation, workspace, editor and keyboard preferences stay K-Plex-owned. The two plugins can coexist while you migrate.

If you used ExcaliBrain, think of K-Plex as a continuation of the core spatial-navigation idea with a more self-contained architecture and a wider set of direct graph workflows.
