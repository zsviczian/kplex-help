# Community GitHub and contributing

Have a question, a useful technique or a problem to report? Find the right place to ask, share an example or help improve K-Plex.

Use these links to follow and improve K-Plex:

- **Repository:** [github.com/zsviczian/kplex](https://github.com/zsviczian/kplex)
- **Issues:** [github.com/zsviczian/kplex/issues](https://github.com/zsviczian/kplex/issues)
- **Community:** [community.sketch-your-mind.com](https://community.sketch-your-mind.com)
- **Support:** [ko-fi.com/zsolt](https://ko-fi.com/zsolt)

Bug reports are most useful when they include reproducible steps, expected vs actual behavior, device/Obsidian details, and K-Plex diagnostics when indexing is involved. Contributions are welcome; review the repository's `CONTRIBUTING.md` before preparing a pull request.

> [!tip]
> Because these URLs are also stored as `Related` ontology values, they can appear as URL nodes in K-Plex — the help points to the community using the same graph mechanism it documents.

## Official destinations

For issues, code and release history, visit **[K-Plex on GitHub](https://github.com/zsviczian/kplex)**. For drawing workflows and its separate issue tracker, visit **[Obsidian Excalidraw on GitHub](https://github.com/zsviczian/obsidian-excalidraw-plugin)**. To exchange K-Plex practices and questions, use the **[Sketch Your Mind Community](https://community.sketch-your-mind.com/)**.

The community is also home to **[Sketch Your Mind — the book](https://community.sketch-your-mind.com/sym)**. Learn more at [[08 About/Sketch Your Mind book|Sketch Your Mind book]].
