## Original published release notes

> [!note] Historical record
> The text below comes from the published GitHub release, not a retrospective reconstruction. Follow the links above to the living Help pages, which may describe newer behavior.

- Added lenses (bases style)
  - Moved all lens button under lenses
  - Added cross-links (as a lens)
  - Added lens based styling
- Added support for note thumbnail image and custom alias fields
- Restructured settings a bit
- Added support to add links as children
- Fixed issues with the touch actions (iPad). you can now add children, make connections, etc.
