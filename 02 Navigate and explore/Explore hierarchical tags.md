# Explore hierarchical tags

Move from a broad topic to a more specific one. Center a tag to explore its parent tag, child tags and the notes that use it.

![[Assets/Screenshot - Search tags.png]]

*Type # and a name in Search Vault to distinguish tags from similarly named notes; each result also shows its full tag path.*

## Explore a tag

1. Open **Search Vault** and type `#kplex-help` to search tags in this vault.
2. Choose the tag itself, rather than a note mentioning it.
3. Follow a child tag such as `#kplex-help/how-to` to narrow the topic. Full tag paths in search, history and pins help distinguish similarly named branches.

A slash separates levels: `#project/workshop` belongs beneath `#project`. You can center tags even if tag nodes are hidden around ordinary notes.

![[Assets/Screenshot - Tag hierarchy.png]]

*A tag can be the center of the map. Its narrower topics appear beneath it.*

## Tag a note as you explore

Drag a tag's gate onto a Markdown note in the canvas, history or pins. You can also drop a tag from another canvas into a note's Parents area. Choose **Tag** for topic membership or **Note Type** when the tag should also determine the note's type.

A note has one Note Type. If it already has a different type, choose whether to replace it or keep the new value as an ordinary tag. Replacing the type can retain the earlier value as a tag.

To remove editable membership, use the connector's **Unlink** action. If the tag also appears in the body, inspect Connection details and edit that occurrence in the note. Use the tag connector's conversion action to switch between Tag and Note Type.

These actions change note properties. Try them on your own practice note before classifying important material.
