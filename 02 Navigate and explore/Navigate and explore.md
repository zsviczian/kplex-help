# Navigate and explore

Find a destination, explore its context or return to a useful idea. Choose the navigation tool that matches that job.

## Pick your task

- **Move around the map:** [[Navigating the Plex|Navigating the canvas]] — click, open, pan, zoom and use context menus.
- **Find a destination or a local match:** [[Vault Search vs Find in this Plex|Vault Search vs Find in this canvas]] — includes folder and hierarchical-tag search.
- **Go back or keep a landmark:** [[Past nodes and pins]] — shared, saved history and pins.
- **Retrace this canvas's complete exploration:** [[Footprints and breadcrumbs|Footprints (breadcrumbs)]] — session-only history that keeps repeated visits.
- **Read a file or website:** [[Editor node and web pages]].
- **Explore on a tablet or phone:** [[Mobile and touch]].
- **Rediscover something without a destination:** [[Wander]]

**Try this:** Use the toolbar Vault Search box to navigate to a different note, then the local magnifier to locate one of its displayed neighbors. Find does not change the center. Follow [[02 Find and navigate knowledge]] for a complete route.

## Browse a topic or location

Use [[Tags and folders|tags and folders]] when a topic or file location is a better starting point than a note title.

## Keyboard-first exploration

[[Keyboard navigation]] explains selection and movement between relationship areas. [[Type to select visible nodes]] lets you select a displayed label by typing. Use the [[K-Plex command palette]] to run context-aware actions and the [[Keyboard shortcuts reference]] for defaults and focus rules.

Follow [[11 Work without the mouse]] to practice these together.

## Put navigation to work

Build a [[Build a Map of Content|Map of Content]], [[Rediscover and remember your notes|make an old idea useful again]], or choose another outcome in [[Use cases|What You Can Do with K-Plex]].

For dragging between views and into an editor, see [[Drag drop and reclassify]]. To keep different documents beside different canvases, see [[Note-tab synchronization]].
