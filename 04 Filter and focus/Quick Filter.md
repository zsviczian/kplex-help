# Quick Filter

Need a momentary view of just the relevant notes? Use Quick Filter to narrow the current map by keyword, tag or note type.

![[Screenshot - Quick filters and lenses.png]]

*Quick Filter, layout choices and saved lenses share one panel. These choices refine the visible neighborhood.*

## Narrow this map for a moment

1. Select the funnel button, **Views and lenses**.
2. Enter a keyword, choose a tag or select a note type in Quick Filter.
3. Review the remaining nodes. Clear the filter to bring the rest back.

Keyword matching includes titles, paths, aliases and relationship descriptions. Try `kplex-help/how-to` as a tag in this vault to focus on practical guides.

Choose [[Keep layout vs Reflow|Keep layout or Reflow]] depending on whether you want stable positions or a compact result. The panel can be dragged aside; close and reopen it to return it beside the funnel.

If you want to reuse the same perspective, save a [[Graph Lenses|Graph Lens]] instead. Filters change the view, not your notes.
