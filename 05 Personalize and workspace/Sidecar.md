# Sidecar

Read or edit a note while keeping its connections in view. Open a Sidecar: a normal Obsidian document pane beside the Plex.

![[Assets/Screenshot - Read beside the map.png]]

*A normal Markdown pane sits beside the Plex so you can read or write while keeping the note's context visible.*

## Read and edit beside the map

1. Center a file-backed note.
2. Select the **Sidecar control** on the graph's edge to open its normal Obsidian document pane.
3. Read or edit the note while following its connections in K-Plex.

Move the Sidecar left, right, above or below the graph with its position control. It can display Markdown or a supported file view such as Excalidraw. Use [[05 Personalize and workspace/Note-tab synchronization|document-following choices]] to decide whether its content should follow your navigation.

You can deliberately attach an eligible adjacent document pane or detach the Sidecar to keep it as an independent tab. Closing K-Plex does not automatically close the document you were reading.

## Give the document more room

Choose **Fold K-Plex tab group** to temporarily hide the graph's entire tab group while leaving its tabs open. The Sidecar then has more room for reading or writing. Use **Unfold K-Plex tab group** on the remaining pane's edge, or repeat the command, to restore the map.

Other tabs in the folded group are hidden too. If the layout cannot safely preserve unrelated panes, K-Plex leaves it expanded. Closing the managed Sidecar restores the folded group.

## Move attention, not the layout

**Ctrl/Cmd+Shift+E** focuses the existing editor and **Ctrl/Cmd+Shift+G** returns to the graph. **Ctrl/Cmd+Enter** centers a selected note and ensures its Sidecar is open. Your [[05 Personalize and workspace/Actions and shortcuts|saved shortcuts]] can override these defaults.

A drawing can keep its chosen drawing or Markdown view when the same file is followed. Use an explicit open or representation command when you want to change it. See [[03 Build and edit/Excalidraw integration]].
