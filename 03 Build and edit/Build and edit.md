K-Plex can **change relationships**, not only display them. Its edits go back to supported sources in your Markdown notes; it does not maintain a separate edge-note database.

## What do you want to do?

- **Tidy relationship properties:** [[03 Build and edit/Manage and clean up ontology|Manage ontology and find its documents]].
- **Connect ideas:** [[03 Build and edit/Create a relationship|Create a relationship]] — use a role and a property field.
- **Plan a future note:** [[03 Build and edit/Create notes and placeholders|Create notes and placeholders]].
- **Change a relationship's direction:** [[03 Build and edit/Drag drop and reclassify|Drag, drop and reclassify]].
- **Understand an edge before editing:** [[03 Build and edit/Connection details and evidence|Connection details and evidence]].
- **Remove something safely:** [[03 Build and edit/Unlink and delete|Unlink and delete]].
- **Create drawing notes:** [[03 Build and edit/Excalidraw integration|Optional Excalidraw integration]].

**Try this:** In two disposable notes, make a Friend relationship using the `Related` property. Open **Connection details…** to see the source. Do not test deletion on important material.

A full guided path is at [[10 Discover by topic/03 Model and edit relationships|Model and edit relationships]].

## Dates and property entry

- [[03 Build and edit/Date properties and daily notes|Date properties and daily notes]] — make native Dates point in the intended spatial direction.
- [[03 Build and edit/Ontology autocomplete|Ontology autocomplete]] — use editor triggers to insert the fields that define relationships.

Try the [[10 Discover by topic/12 Connect dates and daily notes|Dates and daily notes]] discovery route for a complete example.
