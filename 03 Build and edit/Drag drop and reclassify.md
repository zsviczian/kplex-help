K-Plex uses drag-and-drop as a direct manipulation layer over relationships.

- Drag a file from Obsidian onto the **central node** to navigate to it.
- Drop it into a Parent, Friend, Challenger or Child area to open the linking dialog with that role selected.
- Drag an existing related node into another relationship area to reclassify the connection.
- Drag a gate to a pin or Past nodes entry to create that gate's relationship.

Valid drop areas light up while you drag. K-Plex updates the visible graph immediately while it writes the underlying note change, then authoritative metadata catches up.

For a safe editing habit, follow reclassification with [[03 Build and edit/Connection details and evidence|Connection details]] whenever the original relationship had multiple evidence sources.
