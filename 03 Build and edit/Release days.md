# Follow a release through the journal

Remember when a feature arrived, or explore what changed around a day. These daily notes use the real publication dates of the release archive, not the dates on which this Help vault was edited.

![[Screenshot - Release day journal.png]]

*Desktop: November 5 connects to its release through released on, with earlier on November 2 and later on November 9. The month and journal hub supply broader context above.*

## Try the two routes

1. Center [[Release 0.4.3]] and follow its **released on** Friend connection to [[2026-11-09]].
2. Follow the **earlier** Parent to [[2026-11-05]], then its **later** Child to return. The chain crosses days without an entry.
3. Open [[2026-10-24]] to see two releases on one day. Version order lives in each release page's **Previous / Next**, independently of the journal chain.
4. Compare [[Example - Date and a daily note]]: it uses a scalar Date property, while release days use explicit inline wikilinks.

Browse [[Release days - September 2026]], [[Release days - October 2026]] or [[Release days - November 2026]]. The October chain retains the existing October 9 Date-property demonstration; that day is an example, not a claimed release.

Use the Pins calendar to navigate these dates. A dot marks an existing Daily Note. Selecting another, missing day asks before creating it; it does not create a full calendar of notes.
