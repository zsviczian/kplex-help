**Outcome:** A rough sketch becomes a developed idea you can explain, challenge and connect to other work, without losing the original visual thinking.

**Requires:** Install the Excalidraw plugin to create and edit drawing notes.

## Try it: develop one idea card

Create an Excalidraw note with a small sketch and a sentence stating its main idea. Make that note the center of K-Plex. Keep the drawing open in the central editor or Sidecar while exploring its relationships.

Use the Idea Compass as four prompts. What broader idea or source does this come from? What could it lead to? What supports it? What challenges it? Connect existing notes where you have answers and create placeholders where a question deserves more work.

Return to the drawing and improve it using what you discovered. Keep a large visual exploration in Excalidraw, or make separate drawing notes when individual ideas deserve independent connections. K-Plex connects the notes; Excalidraw holds their visual content.

**Done when:** You can explain the idea, show where it came from, describe a possible application and acknowledge a meaningful objection.

## Share the reasoning, not just the finished picture

Use fullscreen or Zen mode to walk someone through the central sketch, its supporting notes and its alternatives. Open a drawing when you need detail and return to the graph for context. This is an interactive explanation rather than an automatically generated slide deck.

Node images can make important notes recognizable, but this workflow does not require selecting an Excalidraw focus frame as a graph card. That frame-selection integration is not covered as an available capability here. Local images also avoid the separate permission needed for remote node images.
