# Build a Map of Content

Have useful notes scattered across a subject? Gather them around one starting point so you can return to the topic without searching from scratch.

![[Assets/Screenshot - Expanded neighbors.png]]

*The workshop plan stays central while the material branch reveals its two source notes one level further down.*

**Outcome:** A useful starting point for a subject, assembled from notes you already have—not another index you must maintain by hand.

## Try it: make a home for a subject

Create a note for a topic you keep returning to, such as “Home renovation,” “Visual thinking” or “My next article.” Pin this Map of Content (MoC) in K-Plex, then explore related notes without keeping the MoC at the center.

When you find something worth including, connect it to the pinned MoC. For a note that belongs under the MoC, drag that note's **Parent gate** onto the MoC pin. From the MoC's perspective, the note becomes a Child. Use Friends for related context rather than putting every useful note into the hierarchy.

Return to the MoC and look for gaps. Group a cluster under a more specific note, link a useful counterpoint, or create a placeholder for an idea that still needs writing. Add a short introduction to explain what this collection is for.

**Done when:** You can start at the MoC, find the main strands of the subject and explain why each belongs there.

## Keep the distinction clear

The graph is built from relationships in your notes. It does not automatically write a table of contents into the MoC's body or choose an editorial reading order. Add prose or explicit Previous/Next links where order matters.

Keep the MoC centered in a second Plex while dragging notes from another view, or use the pin-and-gate workflow above. See [[03 Build and edit/Drag drop and reclassify]].
